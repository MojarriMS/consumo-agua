## 🧩 Descrição
Este projeto foi desenvolvido para analisar o **consumo mensal de água** em diferentes tipos de imóveis (**comercial**, **apartamento** e **casa**) e fornecer mensagens de alerta ou incentivo conforme o perfil de consumo.

Ele utiliza **estruturas de decisão** (`if/elif/else` ou `match/case`) e **operadores lógicos** (`and`, `or`) de forma clara e didática, seguindo os conceitos apresentados na apostila de **Estrutura de Decisão II**.

---

## 🎯 Objetivo
- Incentivar o uso consciente da água.  
- Demonstrar o uso de **condições compostas** em Python.  
- Servir como exemplo prático para estudantes de programação.  

---

## ⚙️ Funcionalidades
- Identificação do tipo de imóvel.  
- Avaliação do consumo mensal de água.  
- Mensagens personalizadas:  
  - **Comercial** ➜ tarifa corporativa (não depende do consumo).  
  - **Apartamento** ➜ consumo econômico, moderado ou excessivo.  
  - **Casa** ➜ consumo moderado ou excessivo.  
- Validação de entradas para evitar valores inválidos.  

---

## 🧠 Tecnologias utilizadas
- **Python 3.10+** (necessário para usar `match/case`).  
- Estruturas condicionais (`if`, `elif`, `else`).  
- Operadores lógicos (`and`, `or`).  
- Conversão de tipos (`float` para consumo).
